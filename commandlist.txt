# branching
feature branch -> replica of our main branch 
git branch -> shows the branches and the current working branch
git checkout branch_name -> used to switch from one the the another branch
git merge feature_branch_name -> used to merge feature_branch with the current_branch
git checkout -v branch_name -> create feature_branch and switch to that feature branch from main branch

# workflow of the branching
1. git branch
2. checkout to source_branch
3. mode changes
4. perform the whole staging-> commiting -> pushing to this new  feature_branch
5. checkout to destination_branch
6. git pull
7. git merge source_branch
8. git push -u origin "destination_branch"
